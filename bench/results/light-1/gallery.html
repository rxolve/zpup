Each set shows one model's answers to the same request, one per format (SVG, Zdog, zpup). zpup and Zdog scenes are also drawn turned by +60° and -60°; an SVG has only the one angle it was written for. In the blind view the formats appear as X, Y, Z in a shuffled order, with one angle each and no error text. The drawing style can still give the format away.
